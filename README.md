## 핵심 개념 정리
- HTML은 구조, CSS는 표현, JS는 동작을 담당한다.
- commit은 지금 상태를 스냅샷으로 확정하는 것, push는 그 커밋들을 GitHub 원격 저장소에 올리는 것이다.
- F12 Network 탭에서 index.html 요청의 Method가 GET, Status가 200으로 뜨는 것을 확인했다 — 브라우저가 서버에 요청을 보내고 정상 응답을 받았다는 뜻이다.
